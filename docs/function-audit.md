## 已修复问题

1. 默认组别改名后，历史记录由数据库正确联动，但默认设置和已打开的录入下拉框仍保留旧名称。
2. 日期列只按天排序，同一天的时分秒被忽略；来源列排序退回日期排序。
3. 检验记录和异常报告的保存窗口忽略用户设置的导出目录。
4. 不良项目刷新后未重算搜索结果，分类筛选被重置但行可见性未同步。
5. 记录可正常导入但签名丢失时，异常报告按钮不可用。
6. 批量修改后返回已保存记录仍显示旧值；移入回收站或清理后的记录仍停留在编辑器。
7. Excel 自动重算失败时，组件关闭异常会中断原本可用的普通表格导出。

上述问题均先由回归场景复现，再修改实现。新增 20 个测试场景，与原有 67 个场景一起执行；本地完整 87 项测试、Ruff 与源码自检通过。

## 验证边界

- Qt 界面测试使用离屏真实控件和事件循环；文件选择和用户点击由测试提供，数据查询、导入导出与后台线程实际运行。
- Windows CI 执行完整测试、打包及实际 EXE 自检。每次发布以相应 GitHub Actions 成功结果与包内 `verification.json` 为准。
- 当前开发环境与 CI 未安装 Microsoft Excel；COM 异常退出通过受控故障模拟验证。没有宣称完成 Microsoft Excel/WPS 实机重算、打印或所有显示缩放比例验收。
- 原表模板和图表布局本次未改变，沿用已有布局与公式回归检查。测试通过表示上述场景通过，不能证明所有硬件与第三方软件组合都无问题。
