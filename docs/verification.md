## 独立审查与修复

独立审查覆盖整个项目，发现六项 Important 问题，分别新增测试重现失败，再修复：

1. SQLite 原生连接上下文退出未关闭文件：改为显式 closing，避免 Windows WinError 32。Windows CI 初轮真实复现两项备份测试失败。
2. 确认放弃编辑仅清除 dirty 标志：改为重新加载已保存内容或清空新建表单。
3. 编辑器丢失逐项备注：选择器加载、刷新与保存均保留关联备注。
4. 演示数据兼容导出缺少来源：在隐藏 N 列保存来源，重新导入仍为 demo。
5. 提交后读取失败清理已提交签名：返回数据在事务内构造，文件回滚仅覆盖事务失败。
6. 扩展编码 eg 改变旧拼接语义：旧格式始终按字符解析；标准格式按明确编码解析。

审查没有要求延后的小问题。独立审查未运行 Windows/Excel COM；Windows 验证由 GitHub Actions 实际执行。Excel COM 的精确效果仍需安装 Microsoft Excel 的用户电脑验证；没有 Excel 时走已测试的 openpyxl 导出。
