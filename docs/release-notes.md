v1.1.43 聚焦全年数据导出性能与稳定排序，不新增页面、不改变统计口径。

- 检验记录页仍保留原有分页查询与总数统计，因此页码、总条数、筛选和排序交互不变。
- 批量导出不再通过 500 条一页反复调用分页 query；改为单次有序流式扫描全部匹配记录，避免每 500 条重复执行一次 COUNT(*)。
- 1825+ 条全年演示数据和更大历史数据导出时，数据库查询次数更少，内存占用也保持分批加载，不需要一次性把全部 ORM 记录读入内存。
- 保留 defects 的 selectin 批量加载和 defect item 的 joined 加载，不引入逐条 N+1 查询。
- query() 内部复用同一组筛选条件，减少重复构造 SQL 条件对象。
- 统一排序稳定性：当主排序字段值相同（例如同一天、同一时间）时，最终 ID 次序会跟随当前升序/降序方向，不再出现主字段升序但同值记录 ID 倒序的情况。
- 报表中心 v1.1.42 的“日期从早到晚导出”继续保持；本轮进一步保证同一时间点内的记录也保持自然升序。
- 新增回归测试：流式 iter_records 不允许执行 COUNT(*)；同日期同时间记录的 tie-breaker 必须跟随 requested direction。
- 数据库 schema、正式数据、导入逻辑、统计公式、Excel 模板结构和 UI 页面结构均不改变。
