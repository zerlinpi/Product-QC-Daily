v1.1.0 在保留原有功能与整体 UI 方向的基础上，提升日常质检操作效率。

- 检验记录筛选区增加明确字段标签、日期范围开关和“一键重置筛选”。
- 选中记录后显示数量，并根据当前选择与回收站状态自动启停编辑、批量修改、删除和恢复按钮。
- 分页按钮会根据当前页自动禁用，减少无效操作。
- 质量分析显示当前统计范围、数据类型与排行口径；报表中心显示实际导出日期范围。
- 仪表盘增加数据范围标签与最后刷新时间。
- 浅色/深色主题统一强化表格选中态、键盘焦点、危险操作、禁用输入和滚动条。
- 新增 Ctrl+1–7 页面导航、Ctrl+F 搜索框聚焦和 F5 页面刷新。
- 数据库结构、统计口径、Excel 原表模板和导入导出逻辑保持兼容。

下载 `Product-QC-Daily-windows-x64.zip` 后完整解压并运行 `Product-QC-Daily.exe`。用户数据仍保存在 `%LOCALAPPDATA%/Product-QC-Daily/`，升级只需替换程序目录。
