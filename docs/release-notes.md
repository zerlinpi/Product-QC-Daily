v1.1.9 根据最新操作审计继续修复长期运行、原表同步和历史演示数据的遗漏，不新增业务功能。

- 质量分析与报表中心在“今天 / 本周 / 本月”等非自定义周期下，每次刷新或导出都会重新计算当前日期，避免软件跨天运行后继续使用昨天或上个月的范围。
- 原表导出的“数据分析表”会同步当前组别名称和当前 a–x 不良项目名称；“工具”字典也一并同步，不再残留模板中的旧名称。
- 演示数据如果生成在当前月份，仍自动打开质量总览；如果生成在历史或未来月份，会自动打开质量分析，并切到本次生成的自定义日期范围与“演示数据”。
- 保留 v1.1.8 的中央生成进度窗口、演示数据隔离、Windows 原生桌面 UI 和现有七页结构。
