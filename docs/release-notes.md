v1.1.7 将现有界面进一步收敛为正常 Windows 桌面软件的系统级观感，不新增业务功能。

- Windows 打包版优先使用 Qt 的 WindowsVista/Windows 原生 style，不再统一强制 Fusion。
- 应用字体继承系统 UI 字体；标题、卡片、按钮、输入框、表格行高和页面留白改为更紧凑的桌面软件尺度。
- 左侧导航改用系统标准图标，去除字符图标；导航面板不再固定深蓝品牌色，而是随浅色/深色主题使用系统中性色。
- 滚动条与复选框指示器交还系统 style 绘制；表格表头、状态栏、菜单、下拉列表和弹窗保留统一但更接近 Windows 的视觉。
- “跟随系统”模式会响应系统浅色/深色变化，Windows 标题栏同步切换深浅色。
- 保留 v1.1.6 的 Excel 连续表单、导出中央动画、导出完成提示和下拉菜单优化。
