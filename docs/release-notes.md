v1.1.10 继续基于现有功能收口 Windows 桌面 UI 与操作流程问题。本轮完成全仓源码、测试、构建、配置及文档审计，不新增业务模块。

- 检验记录右键某一行时会先把该行设为操作目标；如果鼠标所在行已在多选范围内，则继续保留原多选。
- 演示数据仅在完整生成范围都位于当前月时进入质量总览；历史、未来或跨月范围自动进入对应自定义日期的质量分析。
- “生成演示数据”窗口会在关闭前检查日期顺序、参与组别和不良项目权重，错误直接在窗口内提示。
- 不良项目编辑和组别编辑移除 Windows 问号帮助按钮，保存作为默认按钮，窗口行为与其它编辑弹窗保持一致。
- 新增/改名组别若重名，以及不良项目编码若重复，会显示具体中文原因。
- 保留 v1.1.9 的跨天日期同步、原表动态名称、Excel 导出布局与 Windows 原生桌面 UI。
