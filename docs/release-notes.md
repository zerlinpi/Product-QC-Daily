v1.1.45 修复年度 Excel 导出的统计快照、图表范围说明和打印完整性问题。

- 明细、逐项不良、摘要与图表使用同一批记录，修复跨 500 条读取时混入更新后数据的问题。
- 保存路径选择期间记录数变化时提示刷新重试，已有文件不被覆盖。
- 原表六张图表保留布局和设计，明确全年/区间与截止周口径，正确显示跨年 ISO 周；超过八组的返工归入“其他组别”合计。
- 超过 500 条时扩展打印范围并重复表头，原始模板保持不变。
- 复用明细表列边界，减少大数据导出中的重复扫描；不减少记录、签名、图表或样式。
- 增加 SQLite 逐字段与 XLSX 图表 XML 回归矩阵：2026 年 1825 条、2024 闰年 1830 条及 0～10000 条边界；两种格式的年月日、跨月、跨年和来源隔离。
- 对用户两份原始模板完成结构比对，保留四个工作表和六张图表。
- 正式 ZIP 同时提供 SHA-256 校验文件；发布继续要求双平台测试、Ruff、Windows onedir 和真实 EXE 自检成功。

Excel/WPS 实机打开、重算、滚动、保存后重开及打印验收尚未完成，不能以自动化结构检查替代。WPS 专有图片对象兼容限制和完整证据见 docs/export-stability-v1.1.45.md。
