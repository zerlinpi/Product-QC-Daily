v1.1.14 在现有功能基础上继续优化 Windows 报表操作和标准 Excel 明细报表样式；不新增业务模块、不修改数据库 schema，也不改变原表兼容模板。

- 报表中心使用原生 QGroupBox 分区，导入和导出按钮改为紧凑 Windows 桌面操作布局。
- 标准“检验记录”采用 A4 横向打印设置、重复表头、隐藏工作表网格线、合理页边距和针对内容优化的列宽；长备注自动换行。
- 合格/返工判定使用轻量单元格强调，数据值、月份筛选、重新导入和来源隔离逻辑保持不变。
- “月度统计”增加合计行、检验/抽检/不良数量数据条、不良率/返工率数据条，并继续保留两张原生 Excel 趋势图。
- 图表仅引用月份行，不将“合计”行计入趋势；统计摘要、不良明细和不良项目分别优化打印方向、列宽和可读性。
- 原表导出仍走独立模板路径，原有 4 个 Sheet、6 张图表、公式、冻结窗格、500+ 连续表单及外部模板兼容规则未参与本轮样式调整。
- 完整 pytest 为 142 项；Linux/Windows Ruff、pytest、Windows onedir 和实际 EXE self-test 以 GitHub Actions 结果为准。
