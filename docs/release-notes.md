v1.1.28 继续完成整套 Windows 原生桌面 UI 的全局一致性收口，把页面、筛选区、表单、复选项、对话框与主窗口外壳统一到同一套 desktop metrics；不新增业务功能，数据库 schema、统计口径和 Excel 导入导出结构保持不变。

- 新增统一 desktop size tokens：主窗口默认/最小/最大尺寸、侧栏宽度、按钮最小宽度、字段高度、筛选/搜索字段宽度、表格行高、图表最小高度与表单对话框宽度集中定义，不再散落硬编码。
- 所有普通、主操作和危险按钮统一最小 84×28；QDialogButtonBox 的保存/取消等标准按钮同步使用同一尺寸，仍由 WindowsVista/Windows 原生 style 绘制。
- 质量总览、日检录入、检验记录、质量分析、不良项目、报表中心、系统设置中的文本框、下拉框、日期/时间、数字输入统一最小高度 28px。
- “自动时间 / 下一条沿用 / 日期筛选 / 回收站 / 自动备份 / 启用项目 / 启用组别 / 演示数据组别”等复选项统一 28px 点击高度，提升不同页面间的操作一致性。
- 不良项目选择器的搜索、分类、件数输入与行复选框同步 desktop metrics；动态生成的控件不再与静态表单产生高度漂移。
- 组别编辑与不良项目编辑统一使用 460px 表单对话框宽度；演示数据与导入预览保留其内容型大窗口尺寸。
- 新增 field_label / form_row helper：所有页面、QFormLayout、筛选栏和导入预览的字段标签统一从同一入口生成，使用 fieldLabel 视觉角色、buddy 关系与一致的键盘导航语义；页面中不再保留手写 fieldLabel。
- 主窗口默认 1440×920、最小 1080×720、恢复窗口尺寸边界、176px 侧栏和 28px 导航行高统一引用全局尺寸 token。
- 图表、签名预览、分析表格、选择器表格、进度弹窗、导入预览与演示数据窗口的内容型尺寸也集中成公共 token；不同内容仍保留不同规格，避免为了“统一数值”而破坏信息密度。
- 所有自适应页面统一使用 WIDE_LAYOUT_BREAKPOINT，不再出现报表页与其它页面在同一窗口宽度下切换时机不同的问题。
- 演示数据不良项目表的文本单元格改回标准 QTableWidgetItem 渲染，选中态、hover、内边距和深浅色行为与其它数据表一致。
- 确认、信息、错误、导出完成和“软件已运行”提示统一复用原生消息弹窗规范；标准“确定 / 取消”按钮与其它对话框保持同一尺寸、标题栏和默认键行为。
- 检验记录中的“批量修改组别 / 批量修改检验员”不再使用独立 QInputDialog，改为复用统一单字段表单弹窗，字段标签、控件高度、对话框宽度和按钮规格与其它编辑弹窗一致。
- 新增全局控件尺寸、复选项尺寸、表单字段标签角色、内容尺寸 token、消息弹窗与单字段弹窗回归；完整 pytest 为 172 项。
- 实际打包 Product-QC-Daily.exe --self-test 同步验证按钮尺寸、页面字段高度、动态不良项目控件、设置页表单标签与主窗口布局规范。
