v1.1.8 继续优化 Windows 桌面 UI，并修复演示数据“生成后看不到”的实际使用问题，不新增业务功能。

- 点击“生成演示数据”后使用中央进度窗口反馈生成过程；完成后自动进入质量总览，并切换到“演示数据”范围，无需再手动选择数据来源。
- 演示参数窗口改为“生成范围 / 参与组别 / 不良项目出现频率”三个桌面分组，主按钮改为“生成并查看”。
- 设置页基础设置保存按钮不再横向撑满，数据维护操作改为固定网格，更接近常规 Windows 工具软件。
- 表格导入预览窗口移除多余的 Windows 上下文帮助按钮并统一边距。
- 保留 v1.1.7 的 Windows 原生 style、系统字体、系统图标、紧凑表格与浅/深色标题栏同步。

下载 `Product-QC-Daily-windows-x64.zip`，完整解压后运行 `Product-QC-Daily.exe`。升级只替换程序目录，用户数据仍保存在 `%LOCALAPPDATA%/Product-QC-Daily/`。
