v1.1.46 修复原表导出后的月份切换与不良项目中文显示，并加入 Windows 签名发布校验。

- 原表“数据分析表”A2 恢复下拉选择：“全部”或具体年月。跨年月份不混淆，部分月份仅统计本次导出范围内的记录。
- 上方三图按所选期间重算，下方三图仍为所选期间的截止周，明确周口径；保留六图位置、尺寸和样式。
- “成品日检表”的时间列支持原生筛选；明细报表继续使用月份筛选。
- 两种报表的不良项目改为可读名称；演示数据使用真实中文项目名。隐藏编码保留统计与导入关联，改名不匹配时明确提示核对。
- 原表中文内容按需换行并增加行高，修复扩展空白行覆盖已计算行高的问题；保留原列宽、字体、边框、模板与全部记录。
- 增加 LibreOffice 实际重算门禁，覆盖全年、月份切换、空月、跨年、闰日及保存后切回全年，逐张核对六图缓存与单元格值。
- Windows 发布包增加 Authenticode 状态报告与可配置的可信签名接入。启用签名后，缺失、失效、发布者不符或缺少时间戳会阻止发布。
- 延续双平台 pytest/Ruff、Windows onedir、真实 EXE 自检和 ZIP SHA-256 门禁。

**信任提示尚有外部前提：**目前未提供经过身份验证的代码签名服务，未签名包仍可能出现 Windows 提示；请以包内 `signature-verification.json` 的实际状态为准。启用签名需要维护者完成账户与身份验证，不能靠重新打包解决；有效签名也不保证新文件立即免除 SmartScreen 信誉提示。详见 docs/windows-signing.md。

**Excel/WPS：未完成实机验收。**已通过的结构与 LibreOffice 重算检查不代表 Windows Excel/WPS 的实际显示、滚动、保存与打印均已通过。详见 docs/export-stability-v1.1.46.md。
