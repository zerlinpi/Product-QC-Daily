下载 `Product-QC-Daily-windows-x64.zip`，完整解压，双击 `Product-QC-Daily.exe`。无需 Python、Excel 或服务器。

包含快速检验录入、记录与回收站、质量分析/Pareto、24 项初始字典、Excel 导入导出、签名、完整备份恢复、模拟数据和主题设置。

用户数据保存在 `%LOCALAPPDATA%/Product-QC-Daily/`。升级仅替换程序目录。首次使用前请在设置中填写检验员，并通过报表中心导入原表；异常数据需按报告核对。

已有用户关闭旧程序后，解压新版本到新的程序文件夹即可继续使用原数据库。若曾选择外部旧模板，请清空系统设置中的 Excel 模板路径以使用新内置模板。

压缩包内 `verification.json` 是 Windows 构建环境运行该 EXE 的自检结果。该构建未经商业代码签名，Windows 可能显示 SmartScreen 提示。
