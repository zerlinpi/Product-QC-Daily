v1.1.26 继续对整套 Windows 原生桌面 UI 做组件级一致性收口；不新增业务功能，数据库 schema、统计口径、Excel 导入导出结构保持不变。

- 图表颜色全面改为主题感知：坐标轴、文字、折线、柱形、面积填充、Pareto 累计线和 80% 参考线都从统一 palette/semantic color 读取，浅色/深色主题切换时同步刷新。
- MainWindow 切换主题后会主动刷新所有 ChartWidget/ParetoWidget，不再只更新 Qt 标准控件。
- 建立统一摘要文字层级：刷新时间、记录数量、当前选择、分页数量、导入文件状态、组别数量、不良项目合计等统一使用 summary 视觉角色。
- 新增 dialog_button_box helper：所有标准对话框按钮统一 28px 最小高度、AutoDefault 策略和默认主按钮行为，同时继续使用系统原生按钮绘制。
- 不良项目编辑、演示数据、导入预览、组别编辑等对话框统一迁移到同一标准按钮体系。
- 页面滚动容器统一关闭横向滚动条，避免自适应布局下出现多余横向滚动。
- 表格表头最小高度统一为 28px，与 28px 数据行形成一致的桌面数据表节奏。
- 主窗口侧栏边距与顶部栏边距迁移到统一 token：侧栏 8/10/8/8，顶部栏 14/4/14/4，顶部栏最小高度 36。
- 新增 form_grid / content_grid 两套公共布局 helper：表单筛选网格统一 12px 水平 / 8px 垂直间距，内容网格统一 8px 间距。
- 质量总览、日检录入、检验记录、质量分析、报表中心、系统设置、演示数据对话框全部迁移到统一网格 helper，消除各页面手写间距导致的后续漂移。
- 新增组件级 UI 回归：对话框按钮、摘要文字、主题色、滚动区与网格规范均纳入测试；实际打包 EXE self-test 同步覆盖组件一致性。
