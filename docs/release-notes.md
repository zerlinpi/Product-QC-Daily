v1.1.24 继续优化 Windows 原生桌面 UI 的视觉层级与工具页一致性；业务功能、数据库 schema、统计口径和 Excel 结构保持不变。

- 报表中心改为更清晰的桌面工作流：导入文件状态独立显示，导出范围使用强调状态文本，导出动作右对齐；筛选区在窄窗口自动切换为 2×2 布局。
- 系统设置统一改为原生 QGroupBox 分组；基础设置使用右对齐表单标签，保存设置放到右侧；组别表格按名称/状态/排序合理分配列宽。
- 数据维护按“备份与恢复 / 本地数据 / 演示数据”重新组织，系统动作增加 Qt 原生图标，不引入自定义 Web 图标或卡片样式。
- 不良项目页增加可清空搜索、项目总数/启用数、当前选择反馈，并优化列宽分配与双击编辑提示。
- 表格通用细节继续收口：隐藏无意义左上角按钮、统一文本省略、设置最小表头宽度，并为启用/停用状态提供一致颜色。
- 导入预览增加状态筛选工具栏和当前显示数量；正常、重复/冲突、异常/无法识别在状态列使用不同提示色。
- 新增/编辑不良项目与组别对话框统一表单标签对齐、占位提示和默认焦点；任务进度弹窗加宽并支持说明文字换行。
- 浅色/深色主题补齐原生禁用文字、链接色与中间边框色；页面标题提升至 14pt、指标数字提升至 18pt，同时继续使用系统字体。
- 新增工具页与对话框 UI 回归；实际打包 EXE self-test 同步验证报表自适应布局、不良项目搜索和设置页状态。完整 pytest 预期为 157 项。
