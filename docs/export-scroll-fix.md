# v1.1.4 导出滚动与路径窗口修复

## 根因

原表模板虽然已经清空业务数据，工作表视图仍保存 `topLeftCell="B453"`，选中单元格为 `I454`，选区为 `I454:I455`。旧导出只写入 `freeze_panes="C2"`，openpyxl 会保留原来的滚动位置及选区，形成相互矛盾的冻结窗格状态。工作簿还默认打开数据分析页，其他页保留旧选区。

路径窗口使用 Qt 中文文件对话框，其内置文件夹侧栏也名为 `sidebar`，匹配了软件主导航的 `QFrame#sidebar` 样式。实测浅色模式下，侧栏背景为 `#15243e`，文字为 `#172640`，宽度只有 75 像素，导致文字难以辨认。导出默认目录不存在时，Qt 会回退到上一次目录或工作目录，没有按设置进入预期位置。

## 修复范围

- 导出时重建一致的工作簿/工作表视图，从 A1 开始，默认选中记录页，启用横纵滚动条和工作表标签。清理其他窗口、旧分割线及多工作表同时选中状态。
- 原表仍冻结首行和前两列，各窗格选中单元格与其范围保持一致；其他模板页取消旧冻结/分割。明细及异常报告冻结首行，选区从 A2 开始。
- 模板制作工具和外部模板导出使用相同修复；源模板文件不被修改。内置模板仅替换五个 XML 部件中的视图节点，单元格、样式、六张图表、图片布局和其他压缩内容保持不变。
- 主导航改用专属对象名，避免影响文件对话框。三处 Excel 导出入口共用中文保存窗口，保留目录导航、格式选择、覆盖确认与取消行为。
- 创建设置中的目标目录后再显示窗口；无法创建时沿用中文错误提示。窗口按可用屏幕大小设置尺寸，侧栏保持可读宽度。无扩展名时补齐 `.xlsx`；返回路径统一为当前系统的原生路径格式。
- 外部模板即使把“成品日检表”设为隐藏，也不会因设置默认页失败；导出结果会恢复主记录表为可见并从该页打开，源模板文件仍保持不变。

## 回归与边界

- 覆盖原表/明细的 0、1、505 条记录，重新加载生成文件后检查冻结区域、滚动位置、选区及活动页。

- 额外覆盖外部模板隐藏主记录表的情况，制作模板和正式导出均可恢复主表可见/活动状态，同时源模板字节不变。
